# YouTube 观看增强助手

Chrome Manifest V3 扩展。它只针对 `https://www.youtube.com/*` 页面运行，在 YouTube 上提供三个小功能：

1. **网页全屏**：让当前播放器铺满浏览器内容区，同时保留标签栏、地址栏和窗口边框；
2. **单视频循环**：让当前正在播的这一个视频播完自动重播；
3. **频道「全部播放」**：在频道视频页把当前排序下列出的视频一键合成一个播放列表。

代码量很小，全部逻辑集中在 `content.js`，样式在 `content.css`，没有后台脚本、没有任何额外权限。

---

## 安装与更新

1. 打开 `chrome://extensions`；
2. 打开右上角「开发者模式」；
3. 点「加载已解压的扩展程序」，选择本目录；
4. 更新代码后：在扩展卡片点「重新加载」，再刷新已打开的 YouTube 页面。

> 因为改动的是 content script，改代码后必须**重新加载扩展 + 刷新 YouTube 页**才生效。

---

## 功能一：网页全屏

播放器控制栏右侧（原生全屏按钮的**左侧**）会多一个网页全屏按钮。

### 用法
- 点击按钮进入「网页全屏」：当前播放器被放大铺满浏览器可视区域，页面其余部分被黑色遮罩盖住；
- 再次点击该按钮，或按 `Esc` 退出，页面会恢复到原来的滚动位置，之前获得焦点的元素也会被还原；
- 支持普通视频、播放列表、直播、广告阶段和 Shorts。

### 特点与细节
- **不是** YouTube 原生全屏：标签栏、地址栏、窗口边框都还在，适合一边看视频一边操作浏览器；
- 保留字幕、播放器菜单、画质菜单以及 YouTube 原生全屏按钮；
- 窗口被拉宽、收窄、最大化或还原时，会自动重新适配铺满；
- 进入期间会把播放器临时移动到页面顶层（`<body>` 下），这是为了绕开 YouTube 宽屏布局重排造成的“把播放器压到黑幕下”的层叠问题；退出时再放回原位置；
- 若 `Esc` 时播放器正开着某个菜单/弹层，会先等它收起，避免误退全屏。

---

## 功能二：单视频循环

网页全屏按钮旁边还有一个循环按钮。

### 用法
- 点击开启（图标变蓝）后，**当前这个**视频播到结尾会自动重播；
- 再次点击关闭。开启状态对之后切到的每个视频保持生效，直到手动关闭。

### 特点与细节
- 只作用于当前正在播放的单个视频，不是整条播放列表循环；
- 通过给播放器监听 `ended` 事件实现，切换视频后自动绑定到新的视频元素。

## 功能三：频道「全部播放」

在某个频道的「视频」页，视频列表上方的排序行（最新 / 最热门 / 最早 那一排）**最右侧**会多一个播放图标按钮。

### 用法
1. 打开某频道 → 「视频」页；
2. （可选）切换到想要的排序：最新、最热门或最早；
3. 若列表没显示完，先向下滚动，让 YouTube 加载出更多视频；
4. 点击播放按钮 → 会打开一个新的播放列表页面，按当前列表顺序播放已加载的视频（最多前 50 个）。

### 特点与细节
- 按钮会跟着排序行自动出现/消失；切换排序、页面导航、列表刷新后都会自动重新放置；
- 悬停可看到提示，例如「全部播放当前列表（最新，前 50 部）」；
- 只收集当前页面上**已经加载、可见**的视频链接，因此想要更多视频就要先往下滚动加载。

## 工作原理

扩展只在 `https://www.youtube.com/*` 上以 content script 方式本地运行（见 `manifest.json`），核心逻辑：

1. **找到“真正的”播放器**：页面上常存在多个 `#movie_player`（切换视频、广告、预览等会产生），脚本按“是否在播放、当前时间、可见面积、是否在活动布局”等打分，选出正在显示的那个；
2. **插入按钮**：定位到播放器右侧控制栏的原生全屏按钮，把我们的按钮插在它旁边，并实时同步尺寸；
3. **网页全屏布局**：通过 CSS 把播放器 `position: fixed` 铺满视口，用黑色遮罩盖住页面其余部分，并解除播放器祖先链上 YouTube 加的各种 `transform` / `filter` / `contain` / 层叠限制；
4. **应对 YouTube 重排**：YouTube 会频繁重建播放器 DOM（尤其宽屏布局切换）。脚本用 MutationObserver + 定时器监听，一旦播放器被重建/移动就立刻重新打标记、重新铺满，并把播放器临时挂到 `body` 顶层来保证它始终盖在黑幕上；
5. **退出恢复**：退出时移掉标记、放回播放器、移除遮罩，并恢复滚动位置与焦点。

## 已知限制

- 依赖 YouTube 页面 DOM 结构。YouTube 改版后，播放器/排序行结构变化可能让某功能失效，需要随新版 DOM 适配；
- 只在 `https://www.youtube.com/*` 下注入，其它页面不运行；
- 频道「全部播放」只基于**当前已加载**的视频，超过 50 个的部分需要滚动加载后再点；
- 跨域 iframe 内的视频不读取（本扩展也不涉及）。

---

## 建议手动验证清单

- 普通视频 / Shorts / 播放列表 / 直播 / 广告阶段：
  - 网页全屏进入、退出、`Esc` 恢复滚动位置；
  - 进入后拉宽、收窄、最大化、还原窗口；
  - 循环开启后单视频重播、关闭后停止；
- 视频进行中切换下一个视频，网页全屏与循环是否正确跟随；
- 频道视频页在「最新 / 最热门 / 最早」间切换后「全部播放」按钮是否跟随、能否正确生成播放列表。
