# DyD (抖typ下载器) v3.0.3 逆向分析报告

> 生成于 2026-09-06。分析对象：`C:\01Necessity\ToolSoftwares\DyD-win-3.0.3-ia32`
> 产物目录：`scratchpad/app/`（asar 解包原文）、`scratchpad/deob/`（去混淆后的业务代码）

## 1. 这是什么

- **框架**：[electron-egg](https://github.com/dromara/electron-egg)（国产 Electron 脚手架，作者"公众号：分享角落"）。
- **前端**：Nuxt 2 + Element UI，编译产物在 `public/dist/`（纯 UI，无业务）。
- **后端（主进程）**：`public/electron/`，共 **147 KB**，是整个工具的真正核心。
- **打包**：`打包Win.bat` → `npm run encrypt`（javascript-obfuscator 混淆，**非加密**，可完全还原）→ electron-builder 32 位。

### 体积构成（asar 解包后 26.2 MB）

| 部分 | 体积 | 说明 |
|---|---|---|
| `node_modules` | 16.1 MB | 依赖，其中 rxjs 4.5M / socket.io 2.3M / axios 1.6M / lodash 1.4M |
| `public/dist` | 9.5 MB | Nuxt 前端，光字体 `_nuxt/fonts` 就 3.9 MB（125 个 ttf） |
| **`public/electron`** | **147 KB** | **业务逻辑全部在这里** |

外层 `DyD.exe`(134 MB) + `*.dll` + `*.pak` + `locales/` = Electron/Chromium 运行时，与业务无关。

## 2. 下载逻辑（核心机制）

### 2.1 关键设计：不逆签名，靠"寄生"真实网页

工具**不自己计算**快手/抖音的反爬签名（`__NS_sig3`、`sig`、`a_bogus`、`X-Bogus`…）。它的做法：

```
用户粘贴主页/作品链接
   → 主进程开一个真实的 BrowserWindow 打开 kuaishou.com / douyin.com
   → 网页自己去请求官方 API（带完整 Cookie、签名、风控参数）
   → session.webRequest.onBeforeSendHeaders 在"请求发出前"截获：
        details.url            官方 API 地址（已含签名 query）
        details.requestHeaders 请求头（含 Cookie）
        details.uploadData     POST body（GraphQL query）
   → 用 axios 把这次请求"原样重放"一遍，拿到 JSON 响应
   → 从 JSON 里解析出视频/图片直链，存进 this.tasks[作品id]
   → 下载时用 electron-dl / 自写 axDownloader 拉直链存盘
```

> 推论：**网页能正常加载出内容 = 能采集；网页被风控拦、或官方改了接口/字段 = 采集失效。**
> 这正是快手部分坏掉的根因所在。

### 2.2 模块地图（去混淆后在 `scratchpad/deob/`）

| 文件 | 作用 |
|---|---|
| `controller/main.js` | IPC 入口。前端调 `controller.main.openCollectionWindow` / `dispatcherDownload` / `interruptDownload` / `chooseSaveDir` … 按 `msg.platform` 转发给对应 service |
| `service/collection.js` | **公共采集窗口**。`open(url)` 建 BrowserWindow，挂 `onBeforeSendHeaders` / `will-redirect`(urlInterceptor) / `did-finish-load` 三个钩子，UA 固定 `Chrome/126.0.0.0` |
| `service/ks.js` | **快手**采集+下载（见 `ks.annotated.js` 注释版） |
| `service/dy.js` | 抖音，同结构 |
| `service/tk.js` / `xhs.js` / `vx.js` | TikTok / 小红书 / 视频号 |
| `common.js` | 文件名过滤、目录准备、`pkgTask` 归一化、进度 IPC(`downloadProgress`/`collectedTask`)、`作品信息.txt` 写入 |
| `addon/axDownloader/index.js` | 自写下载器：单文件流式下载 + 图集批量下载 + 代理 + 取消 |
| `addon/chromeExtension/index.js` | 从 `extraResources/chromeExtension/` 加载 crx（**该目录为空，功能未启用**） |
| `addon/autoUpdater` `awaken` `tray` `security` | electron-egg 自带插件 |

### 2.3 快手采集分支（`service/ks.js` → `onBeforeSendHeaders`）

| 分支 | `type` | 命中条件（URL / body） | 重放方式 | 响应取值路径 | handleFeed kind |
|---|---|---|---|---|---|
| A 主页列表 | home | `com/graphql` 且 body 含 `photoContent on PhotoEntity` | POST 重放 | `data.data.visionProfilePhotoList.feeds[]` | 101 |
| B 单作品 | solo | URL 含 `short-video` 或 `com/f/` | **不重放**，直接 `executeJavaScript` 读 `window.__APOLLO_STATE__.defaultClient`，找 key 含 `VisionVideoDetailAuthor` / `VisionVideoDetailPhoto` | 页面内存 | 102 |
| C 主页(移动) | home | URL 含 `profile/public?` | GET 重放 | `data.data.list[]` | 103 |
| D 单作品(移动) | solo | URL 含 `profile/feedbyid?photoId` | GET 重放 | `data.data.currentWork` | 103 |
| E 图集(分享域) | solo | URL 含 `chenzhongtech` 且 `photo/info` | POST 重放 | `data.atlas.list` + `data.atlas.cdn[0]` | 104 |

**直链字段**（视频）：`photoH265Url`（优先）、`photoUrl`；封面 `coverUrl`。
**已知缺陷**：kind 101/102 的"图文（非视频）"分支在原代码里是**空的** `else {}`，即主页图文/单条图文快手作品本来就取不到图片 URL。

## 3. 快手为什么坏了 —— 诊断与修复位置

快手 2024 下半年起对 `www.kuaishou.com` Web 端做过多轮改造。按可能性排序：

### ① 主页 GraphQL 匹配失效（最可能）
`service/ks.js` 分支 A 依赖 body 里出现字符串 `photoContent on PhotoEntity`。
快手若改了 GraphQL fragment 名 / operationName（如 `visionProfilePhotoList` → 新名），或改走别的接口，
则 `onBeforeSendHeaders` 里**没有任何分支命中**，`this.tasks` 一直空，前端表现为"采集 0 个"。
- 排查：在采集窗口 F12 看 Network，找加载作品列表那条 XHR 的真实 URL / operationName / body。
- 修复：改分支 A 的命中条件与 `resp.data.data.<新路径>.feeds`。

### ② 响应结构 / 字段改名
`visionProfilePhotoList.feeds` 或 `photo.photoH265Url` / `photoUrl` / `coverUrl` 改名 → 采到任务但直链为空 → 下载报 -999。
- 排查：把分支 A 里 `resp.data` 打印出来比对。

### ③ `__APOLLO_STATE__` 没了（影响分支 B 单作品）
快手若从 Apollo 迁到别的状态管理，或把 `defaultClient` 改名 → `executeJavaScript` 抛错，10 次重试全失败。
- 修复：改成解析新的全局状态对象，或改抓 `short-video` 页自己发的 detail XHR（改成"重放"模式）。

### ④ 风控（验证码 / 需要登录态）
UA 硬编码 `Chrome/126.0.0.0`（`collection.js:22`）已过时；`Referer` 加随机 `?r=` 的小 trick 可能触发风控。
网页弹验证码时，重放的 axios 请求会拿到风控页而非 JSON → catch 静默吞掉。
- 缓解：升级 UA 字符串；确保采集窗口里已登录快手；把 catch 里的错误打出来别静默。

### ⑤ H265 直链需要额外鉴权头
`photoH265Url` 有时带时效 token 或需 `Range`/`Referer`。electron-dl 下载 403 时会走 `downloadV` 的重试逻辑换 `photoUrl`。

> **建议的定位顺序**：先在采集窗口开 DevTools 手动翻一次主页，抄下真实的列表接口 URL + body + 响应 JSON，再对照 `ks.annotated.js` 分支 A / kind 101 逐字段改。改完把 `scratchpad/deob` 里的文件重新压回 `app.asar` 即可（asar 无签名校验）。

## 4. "去壳 / 瘦身" —— 无关内容清单

### 4.1 可直接删（与"下载短视频"完全无关）

| 路径 | 理由 |
|---|---|
| `public/dist/_nuxt/fonts/*` (3.9 MB, 125 ttf) | Nuxt 全量打包的中文字体子集，UI 用系统字体即可 |
| `node_modules/rxjs` (4.5 MB) | socket.io-client 的依赖；`config` 里 `socketServer.enable=false` `httpServer.enable=false`，整条 socket/koa 链路没启用 |
| `node_modules/socket.io*`, `engine.io*`, `koa*`, `@socket.io`, `ws`, `cors`, `koa2-cors` | 同上，内置 HTTP/Socket 服务未开 |
| `node_modules/electron-updater`, `builder-util-runtime`, `js-yaml`, `lazy-val` | `addons.autoUpdater.enable=false` |
| `public/electron/addon/autoUpdater/`, `addon/awaken/`, `addon/tray/` | 自动更新 / 协议唤起 / 托盘，非核心 |
| `public/electron/addon/chromeExtension/` + `resources/extraResources/chromeExtension/` | crx 目录为空，功能未启用 |
| `resources/extraResources/dll/myDllDemo.dll` (10 KB) | electron-egg 示例 DLL，代码里无引用 |
| `public/electron/jobs/example/` (`hello.js`, `timer.js`) | 脚手架示例定时任务 |
| `public/ssl/` | 内置 https 服务的自签证书，未启用 |
| `LICENSES.chromium.html` (6.6 MB), `LICENSE.electron.txt` | 仅版权文本，可留可删 |

### 4.2 按需删（只想要快手，就删其它平台）

| 路径 | 属于 |
|---|---|
| `public/electron/service/dy.js` | 抖音 |
| `public/electron/service/tk.js` | TikTok |

> 注意：删平台后要同步改前端（`public/dist/_nuxt/661d37e.js` 等里写死的平台 tab 列表），否则点了会报错。前端是编译产物，改起来麻烦；**更稳的做法是只删 service，前端保留但不用**。

### 4.3 必须保留（下载短视频的最小集合）

```
public/electron/
  index.js  common.js  bin.js
  config/           全部（config.default.js 决定窗口/开关）
  controller/main.js
  preload/          index.js  bridge.js
  service/collection.js        ← 采集窗口
  service/ks.js                ← 快手（要修的就是它）
  addon/axDownloader/  addon/security/
node_modules/  (仅这些)
  ee-core 及其依赖、axios、electron-dl、electron-egg 运行时必需的
  https-proxy-agent、lodash、dayjs、cookie
public/dist/       前端（可删 fonts）
```

理论最小可运行体积：Electron 运行时 + ~3 MB 业务 + 前端。

### 4.4 操作方式

1. 解包：已完成 → `scratchpad/app/`（用 `scratchpad/Extract-Asar.ps1`）。
2. 去混淆：已完成 → `scratchpad/deob/`（用 `scratchpad/deobf2.js` + `polish.js`，靠 `DyD.exe` 当 Node 跑）。
3. 删掉 4.1/4.2 清单里的文件。
4. 重新打包 `app.asar`（`asar pack app app.asar`，需要 Node；或写个反向 pack 脚本）放回 `resources/`。
   asar **无完整性校验**，直接替换即可运行。
5. 若只是修快手：可跳过瘦身，直接把改好的 `service/ks.js`（去混淆版）压回 asar。
